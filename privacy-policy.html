ShipReady — Privacy Policy

Last updated: 23 November 2026

ShipReady is a Forge app for Jira and Confluence that computes a release-readiness verdict (SHIP / SHIP WITH CAUTION / HOLD) for a Jira version, based on the version's issues, blockers and build status, and can optionally write the result as a Confluence page.

What data ShipReady accesses

When you ask ShipReady about a version, it reads, in real time and only for that request:

  • Jira version, issue and build information (issue keys, statuses, priorities, assignee display names).
  • Confluence space information, only when you ask it to write a report.

What ShipReady stores

ShipReady does not store personal data. It does not copy or persist any user account identifiers, does not cache data for more than the duration of a single request, and does not send data to any third-party service. All processing happens inside Atlassian's Forge runtime.
